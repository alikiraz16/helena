# CV / Portfolyo İçin Proje Açıklamaları

Kullandığınız CV formatına veya başvurduğunuz pozisyona göre aşağıdaki seçeneklerden birini kullanabilirsiniz.

## Seçenek 1: Kısa ve Öz (Bullet Points)
**Helena Library Cafe Automation** | *PHP, MySQL, JavaScript*
*   Kütüphane ve kafe ortamı için uçtan uca yönetim sağlayan full-stack web uygulaması geliştirildi.
*   **Görsel Rezervasyon Sistemi:** JavaScript ve CSS Grid kullanılarak masa/sandalye seçimini sağlayan interaktif yerleşim planı tasarlandı.
*   **Veritabanı Yönetimi:** MySQL Event Scheduler kullanılarak rezervasyon sürelerinin otomatik yönetimi ve stok takibi sağlandı.
*   Restful API yapısı ile frontend ve backend arasında asenkron veri akışı (AJAX/Fetch) kuruldu.

## Seçenek 2: Detaylı Açıklama (Projeler Bölümü İçin)
**Helena Kütüphane & Kafe Otomasyon Sistemi**
Kullanıcıların çalışma alanlarını rezerve edebildiği ve kafe hizmetlerinden yararlanabildiği web tabanlı bir platformdur. Proje, müşteriler için kullanıcı dostu bir arayüz sunarken, yöneticiler için kapsamlı bir dashboard sağlar.

*   **Teknik Kazanımlar:**
    *   PHP ile güvenli oturum yönetimi (Session Based Authentication) ve rol tabanlı erişim kontrolü (Admin/User) uygulandı.
    *   Veritabanı normalizasyon kurallarına uygun ilişkisel MySQL mimarisi tasarlandı.
    *   Frontend tarafında Vanilla JavaScript ile dinamik DOM manipülasyonu yapılarak, anlık doluluk oranlarını gösteren interaktif bir rezervasyon haritası geliştirildi.
    *   Sipariş ve stok hareketleri için tetikleyiciler (Triggers) ve zamanlanmış görevler (Events) kullanıldı.

## Teknik Yetkinlik Anahtar Kelimeleri (Keywords)
PHP, MySQL, Relational Database Design, JavaScript (ES6+), AJAX/Fetch API, RESTful Services, CSS3, HTML5, Web Security, Session Management, Full Stack Development.
